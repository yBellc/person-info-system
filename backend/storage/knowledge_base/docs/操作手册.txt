人员信息管理系统操作手册

第一章 入职管理
新员工入职需通过简历导入或手动建档创建人员档案。
入职流程：简历导入 -> 信息确认 -> 账号创建 -> 部门分配 -> 岗位安排。

第二章 在职管理
在职管理包括考勤记录、绩效考核、奖惩管理、调岗调动、合同管理、培训记录。
考勤支持批量Excel导入，绩效按季度考核，调岗需双人复核。

第三章 离职管理
离职流程：离职申请 -> 部门审批 -> 人事审批 -> 领导审批 -> 交接确认 -> 账号停用。
交接项目需接收人、监督人双方确认。

第四章 涉密分级
数据分为公开、内部、秘密、机密四个等级。
用户 clearance_level 决定可见数据范围，低密级用户查看高密级字段时自动脱敏。
