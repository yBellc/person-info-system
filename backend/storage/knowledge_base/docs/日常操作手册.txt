人员信息管理系统 - 日常操作手册

一、考勤管理
1. 人事进入【在职人事管理】→【考勤记录】
2. 支持单条录入和Excel批量导入
3. 考勤类型：出勤、请假、出差、加班、缺席
4. 月度考勤统计报表自动生成

二、绩效管理
1. 人事进入【在职人事管理】→【绩效考核】
2. 考核周期：月度/季度/年度
3. 考核类型：工作业绩、能力素质、态度表现
4. 支持自定义考核指标和权重

三、奖惩管理
1. 奖励类型：嘉奖、三等功、二等功、一等功、荣誉称号
2. 惩罚类型：警告、严重警告、记过、记大过、降级、开除
3. 奖惩记录计入个人档案
4. 奖惩审批需部门+人事+领导三级审批

四、调岗调动
1. 员工可申请调岗或调动
2. 审批流程：部门负责人→人事→单位领导
3. 调动后权限自动更新
4. 所有调动记录留存备查

五、合同管理
1. 合同类型：聘用合同、劳动合同、实习协议
2. 合同到期前30天系统自动提醒
3. 支持合同续签审批流程
4. 合同变更需双方确认

六、统计报表
1. 花名册报表：全员基本信息
2. 党员统计：党员人员信息
3. 学历统计：按学历层次分类
4. 通讯录：联系信息汇总
5. 自定义报表：AI智能生成
