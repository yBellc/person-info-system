人员信息管理系统 - 审批流程操作指南

一、请假审批流程
1. 员工进入【流程审批】→【新建审批】→选择【请假申请】
2. 填写请假类型（年假/事假/病假/调休/婚假/产假）、起止日期、天数、事由
3. 提交后自动进入部门负责人审批
4. 部门负责人审批通过后进入人事审批
5. 全程可在【我的审批记录】中查看进度

二、费用报销流程
1. 进入【流程审批】→【新建审批】→选择【费用报销】
2. 填写费用类型（差旅费/招待费/办公采购/培训费）、金额、日期、说明
3. 上传发票附件（系统自动识别OCR并查重）
4. 经办人→部门负责人→财务审批
5. 审批通过后自动生成会计凭证

三、用章申请流程
1. 进入【流程审批】→【新建审批】→选择【用章申请】
2. 选择印章类型（公章/合同章/财务章/法人章）
3. 填写用章事由
4. 部门负责人审批→印章管理员审批

四、离职审批流程
1. 提交离职申请（提前30天）
2. 部门负责人审批
3. 人事审批
4. 分管领导审批
5. 办理工作交接（双方确认）
6. 账号自动停用

五、审批说明
- 每个流程节点均有审批人，支持会签
- 驳回时必须填写审批意见
- 审批超时可催办或转交
- 所有审批记录永久留存，支持追溯
