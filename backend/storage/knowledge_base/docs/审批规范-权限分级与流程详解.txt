## 二、各类流程审批节点详解

### 2.1 请假审批流程
```
发起人 → 部门主管（≤3天终审）
             ↓（>3天）
         分管领导（≤7天终审）
             ↓（>7天）
         单位一把手（终审）
             ↓
         人事科（备案 + 调考勤）
```
注意事项：
- 产假/陪产假/病假必须上传相关证明材料
- 年休假/婚假/丧假直接终审，但系统自动扣减对应余额
- 紧急情况可先口头请假，上班后1天内补走流程

### 2.2 差旅费报销流程
```
发起人（粘贴发票）
    ↓
部门主管（审核事由真实性）
    ↓
财务科（发票合规性审核、金额核对）
    ↓
分管领导（≤1万终审）/ 单位一把手（>1万终审）
    ↓
财务科（生成凭证 + 出纳打款）
```
注意事项：
- 发票抬头必须正确，税号准确
- 电子发票需查询发票真伪，防止重复报销
- 超标准住宿/交通需提前说明原因并获批，否则差额自付
- 出差补贴（伙食费/市内交通）包干，无需发票

### 2.3 用印审批流程
```
发起人（填写事由 + 上传文件预览/合同扫描件）
    ↓
部门主管（审核）
    ↓
法务/合规（合同类必须审核，非合同类可跳过）
    ↓
分管领导（≤10万终审）/ 单位一把手（>10万终审）
    ↓
办公室（登记用章记录 + 盖章）
```
注意事项：
- 严禁在空白页、空白合同上盖章
- 多页合同必须加盖骑缝章
- 公章带出办公区需单位一把手特批，两人陪同

### 2.4 调岗审批流程
```
发起人（人事科或原部门主管）
    ↓
原部门主管（同意调出）
    ↓
新部门主管（同意接收）
    ↓
分管领导（审核）
    ↓
单位一把手（终审）
    ↓
人事科（更新档案、更新权限、通知相关人）
```
注意事项：
- 交接清单必须完整，原岗位工作全部交接完毕后才能到新岗位报到
- 涉密岗位调岗需额外进行保密审查

### 2.5 离职审批流程
```
发起人（本人或人事科）
    ↓
部门主管（面谈挽留 + 审核）
    ↓
人事科（合规审核：合同/服务期/竞业限制等）
    ↓
分管领导（中层以下终审）/ 单位一把手（中层以上终审）
    ↓
-------- 交接环节（并行）--------
├─ 工作交接（交接人+接收人+监交人签字）
├─ 物品归还（办公室签字）
├─ 财务结清（无借款/无未报销，财务科签字）
└─ 涉密资料归还（涉密岗位须保密管理员签字）
    ↓
人事科（开离职证明、停社保公积金、停用账号）
```

## 三、审批时效规定

| 节点 | 办理时效 | 超时处理 |
|-----|---------|---------|
| 部门主管审批 | 2个工作日内 | 系统自动催办1次，第3天自动抄送分管领导 |
| 分管领导审批 | 3个工作日内 | 系统自动催办，超5天通知单位一把手 |
| 财务审核 | 3个工作日内 | 月末结账期可顺延2天 |
| 出纳打款 | 审批完成后5个工作日内 | 遇月底/年底付款高峰期可顺延 |

## 四、审批特殊情况处理

### 4.1 审批人外出
- 提前设置「代理人」：系统支持审批人设置代理，外出期间由代理人代为审批
- 紧急情况：电话/微信请示审批人，审批人同意后由上一级或人事科代审，事后补手续

### 4.2 审批人出差/请假导致无人审批
- 部门副职代审（如无副职则由分管领导指定）
- 超过3个工作日仍无法审批的，流程自动升级至上一级

### 4.3 拒签/退回
- 审批人拒绝时必须填写拒绝理由，否则无法提交
- 发起人可查看拒绝理由，修改后重新提交（按原流程重新走一遍）
- 同一条流程被退回3次后自动归档，需重新发起

### 4.4 金额累加规则
- 同一事项不得拆分报销以规避审批权限
- 如发现拆分行为：通报批评 + 本次报销全额退回 + 绩效考核扣分
