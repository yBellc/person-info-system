# 人事管理制度 - 模板（单位名称请替换为实际名称）

## 第一章 总则
1.1 目的：为规范本单位人事管理工作，保障员工合法权益，根据国家相关法律法规，结合本单位实际，制定本制度。
1.2 适用范围：本制度适用于与本单位签订劳动合同的全体员工。
1.3 管理部门：人事科（人力资源部）是本制度的归口管理部门。

## 第二章 员工入职管理
2.1 新员工入职需提供以下材料：
    （1）身份证原件及复印件
    （2）学历学位证书原件及复印件
    （3）离职证明（或解除劳动合同证明）
    （4）近期一寸免冠照片4张
    （5）银行卡复印件（用于工资发放）
    （6）健康体检报告（三个月内有效）
2.2 入职流程：
    （1）人事科核验资料 → （2）签订劳动合同 → （3）建立员工档案 → （4）办理工牌 → （5）部门报到 → （6）入职培训
2.3 试用期规定：
    - 劳动合同期限3个月以上不满1年的，试用期1个月
    - 劳动合同期限1年以上不满3年的，试用期2个月
    - 劳动合同期限3年以上或无固定期限的，试用期6个月
    - 试用期工资不低于转正工资的80%

## 第三章 考勤管理制度
3.1 工作时间：
    - 工作日：周一至周五
    - 上班时间：上午8:30 - 12:00，下午14:00 - 17:30
    - 午休时间：12:00 - 14:00
3.2 打卡规定：
    - 实行上下午双打卡制度
    - 迟到/早退15分钟以内：口头警告
    - 迟到/早退15-30分钟：扣半天基本工资的20%
    - 迟到/早退超过30分钟：按旷工半天处理
    - 月度累计迟到早退≥3次：取消当月全勤奖
3.3 旷工处理：
    - 旷工1天：扣当日工资的200%
    - 连续旷工3天或年度累计旷工15天：解除劳动合同
3.4 外出报备：
    - 因公外出需在OA系统填写外出申请，注明事由、时间、地点
    - 因私外出按事假处理

## 第四章 请假管理制度
4.1 各类假期及薪资标准：

    | 假期类型 | 天数 | 薪资待遇 | 审批权限 |
    |---------|------|---------|---------|
    | 事假 | 全年≤15天 | 无薪 | 3天内部门主管；超3天分管领导 |
    | 病假 | 医疗期内 | 不低于当地最低工资80% | 需提供医院证明 |
    | 婚假 | 3天 | 全额发放 | 提前一周申请 |
    | 产假 | 158天（含产前15天） | 生育津贴 | 提前一个月申请 |
    | 陪产假 | 20天 | 全额发放 | 提供出生证明 |
    | 丧假 | 3天（直系亲属）1天（旁系） | 全额发放 | 事后3天内补手续 |
    | 年休假 | 工作满1年5天；满10年10天；满20年15天 | 全额发放 | 提前3天申请 |

4.2 请假流程：
    （1）OA系统提交请假申请 → （2）上传相关证明材料 → （3）部门主管审批 → （4）超权限的上级审批 → （5）人事科备案
4.3 注意事项：
    - 年休假不得跨年度使用，逾期未休视为自动放弃
    - 病假连续3天以上需提供二级以上医院诊断证明
    - 紧急情况可先口头请假，上班后1个工作日内补手续

## 第五章 薪酬福利制度
5.1 工资构成：
    - 基本工资（固定）+ 岗位津贴 + 绩效奖金 + 补贴（交通/通讯/餐补）
5.2 发放时间：每月15日发放上月工资，遇节假日提前发放
5.3 社保公积金：
    - 按国家规定缴纳五险一金
    - 缴费基数按员工上年度月平均工资核定
5.4 福利项目：
    - 节日福利（春节、端午、中秋等）
    - 年度体检（全员免费）
    - 生日慰问
    - 降温费/取暖费（按当地标准）

## 第六章 绩效考核制度
6.1 考核周期：月度考核 + 年度考核
6.2 考核等级：
    - A（优秀，前10%）：绩效系数1.3
    - B（良好，前30%）：绩效系数1.1
    - C（合格，前50%）：绩效系数1.0
    - D（待改进，前8%）：绩效系数0.8
    - E（不合格，最后2%）：绩效系数0.5
6.3 考核结果应用：
    - 与绩效奖金直接挂钩
    - 连续2次D级：岗位调整或培训
    - 年度考核E级：解除劳动合同

## 第七章 员工离职管理
7.1 离职类型：
    - 主动离职：员工提前30天（试用期提前3天）书面申请
    - 被动离职：单位解除劳动合同
    - 合同到期不续签
7.2 离职流程：
    （1）提交离职申请 → （2）部门面谈 → （3）工作交接（填交接清单）→ （4）物品归还（电脑/工牌/钥匙等）→ （5）财务结清 → （6）人事科开离职证明 → （7）社保公积金停缴
7.3 交接要求：
    - 未完成工作清单
    - 在职期间的文件/资料/数据
    - 未结清的借款/报销
    - 所有交接需交接人、接收人、监交人三方签字

## 第八章 附则
8.1 本制度自发布之日起执行，未尽事宜由人事科负责解释。
8.2 本制度如与国家法律法规相冲突，以国家规定为准。
8.3 本制度每年修订一次，如有临时调整以单位正式文件为准。
