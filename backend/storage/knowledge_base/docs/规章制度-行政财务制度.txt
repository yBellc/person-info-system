# 行政财务规章制度 - 模板

## 第一部分：办公管理制度

### 一、办公用品管理
1.1 采购流程：
    （1）每月25日前各部门报下月需求 → （2）办公室汇总 → （3）领导审批 → （4）统一采购
1.2 领用规定：
    - 凭工作证签字领取
    - 打印纸/笔等易耗品按需领取
    - 大件物品（计算器、订书机等）登记使用，离职归还
1.3 节约要求：
    - 打印材料尽量双面打印
    - 下班后关闭电脑、打印机、空调等用电设备
    - 长明灯、长流水现象纳入部门考核

### 二、会议管理
2.1 会议室预约：提前1天在OA系统预约，注明时间、参会人数、所需设备
2.2 会前准备：会议主办部门提前10分钟到场调试设备
2.3 会场纪律：
    - 手机调至静音
    - 准时到会，迟到5分钟以上需在会后向主办部门说明
    - 会议期间避免随意走动

### 三、公章管理制度
3.1 保管：公章由办公室指定专人专柜保管，不得擅自将公章带出办公室
3.2 使用流程：
    （1）填写《公章使用申请表》→ （2）部门负责人签字 → （3）单位领导审批 → （4）公章管理员登记使用
3.3 禁止事项：
    - 严禁在空白介绍信、空白纸上盖章
    - 严禁未经审批用章
    - 严禁个人私自使用公章
    - 违反规定追究当事人及公章管理员责任

### 四、档案管理制度
4.1 归档范围：
    - 上级文件、本单位正式发文
    - 合同协议、会议纪要、人事档案
    - 财务凭证、审计报告、项目资料
4.2 保管期限：
    - 永久：重要合同、人事档案、财务年报
    - 30年：一般合同、会议纪要、项目资料
    - 10年：通知公告、一般性往来文件
4.3 借阅规定：
    - 内部借阅：填写借阅登记，3日内归还
    - 外单位借阅：需分管领导批准，原则上不外借原件

## 第二部分：财务报销管理制度

### 五、总则
5.1 所有支出须"先审批、后支出"，严禁"先斩后奏"
5.2 报销凭证必须合法、真实、有效，发票抬头为本单位全称

### 六、差旅费报销标准
6.1 住宿费标准（每人每天）：

    | 人员级别 | 一线城市 | 省会城市 | 其他城市 |
    |---------|---------|---------|---------|
    | 单位领导 | ≤800元 | ≤600元 | ≤450元 |
    | 中层干部 | ≤600元 | ≤480元 | ≤350元 |
    | 普通员工 | ≤500元 | ≤380元 | ≤280元 |

    注：一线城市指北京、上海、广州、深圳、杭州

6.2 交通标准：
    - 火车：单位领导可坐一等座/软卧，其他人员二等座/硬卧
    - 飞机：科级以上可坐经济舱，特殊情况需提前审批
    - 市内交通：据实报销，优先地铁公交，出租车需写明事由
6.3 伙食补助：
    - 境内出差：100元/天（包干使用，无需发票）
    - 出差天数：出发日和返回日均按1天计算
6.4 报销流程：
    （1）出差申请（提前在OA填写，注明出差事由、时间、地点、预算）
    →（2）领导审批
    →（3）出差结束后5个工作日内填写报销单，粘贴发票
    →（4）部门主管审核 → 财务科审核 → 分管领导审批 → 出纳付款

### 七、日常费用报销
7.1 招待费：
    - 公务接待需提前申请，注明接待对象、人数、标准
    - 工作餐标准：80元/人/餐；宴请标准：150元/人/餐
    - 严禁超标准接待，严禁私人宴请公款报销
7.2 培训费：
    - 外出培训须提前审批，培训合格后方可报销
    - 报销时附培训通知、合格证书复印件
7.3 办公费：
    - 零星采购500元以下：办公室统一采购，凭票报销
    - 500元以上：须提前申请，走采购流程
7.4 报销时限：
    - 费用发生后1个月内必须报销，逾期不予受理

### 八、借款规定
8.1 因公借款：填写借款单，注明事由、金额、预计还款日期
8.2 审批权限：
    - 5000元以下：部门主管 + 财务科长
    - 5000-20000元：部门主管 + 财务科长 + 分管领导
    - 20000元以上：单位一把手审批
8.3 还款要求：
    - 出差借款：出差回来后5个工作日内结清
    - 其他借款：按约定日期归还
    - 前账不清，后款不借

### 九、固定资产管理
9.1 采购流程：
    （1）使用部门申请 →（2）办公室审核预算 →（3）领导审批 →（4）统一采购
9.2 登记入账：
    - 固定资产单价≥2000元，使用年限≥1年
    - 办公室建立台账，财务科入账
    - 使用人签字认领，谁使用谁负责
9.3 报废处置：
    - 达到使用年限或无法使用的，使用部门申请报废
    - 办公室+财务科联合鉴定，领导审批后统一处置
    - 残值收入上缴财务

## 第三部分：保密与安全制度

### 十、保密规定
10.1 涉密人员分级：
    - 核心涉密：接触绝密/机密级资料的岗位
    - 重要涉密：接触机密/秘密级资料的岗位
    - 一般涉密：接触内部/秘密级资料的岗位
10.2 保密要求：
    - 涉密文件按定密等级存放于保险柜，严禁带出办公区
    - 严禁在微信、QQ等互联网渠道传输涉密信息
    - 涉密计算机严禁连接互联网，严禁插入私人U盘
    - 每年签订《保密责任书》，离岗时进行保密审查

### 十一、网络与信息安全
11.1 电脑设置8位以上强密码（字母+数字+符号），每90天更换
11.2 严禁将工作邮箱、工作账号密码告知他人
11.3 外来U盘插入前必须杀毒，严禁打开不明来源的邮件附件
11.4 发生信息泄露事件立即上报，不得隐瞒
