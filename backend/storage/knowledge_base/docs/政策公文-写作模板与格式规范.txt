# 单位公文写作模板与政策文件参考

## 一、常用公文格式规范

### 1.1 公文一般格式
```
──────────────────────────────────────
（红头）XX单位文件
XX〔202X〕XX号  （发文编号）
──────────────────────────────────────

【标题】关于XXXX的通知（请示/报告/函）

主送机关（各部门/各科室/各位同事）：

    正文第一段：说明发文缘由、背景、目的。
    正文第二段：具体事项、要求、措施，分1、2、3点列明。
    正文第三段：执行要求、生效日期、联系方式。

    特此通知。（或：以上请示妥否，请批示。/ 特此报告。）


（右对齐）XX单位（公章）
（右对齐）202X年X月X日

（联系人：XXX   联系电话：XXXXXXX）
──────────────────────────────────────
```

### 1.2 公文标题常用句式
- 关于开展XXXX工作的通知
- 关于XXXX事项的请示
- 关于XXXX情况的报告
- 对《关于XXXX的请示》的批复
- 关于XXXX规定（办法、细则）的印发通知
- 关于召开XXXX会议的通知
- 关于XXX等同志职务任免的通知

### 1.3 发文字号规范
格式：单位简称〔年份〕序号
- 年份用6角括号〔〕，不是[]也不是【】
- 年份为4位完整数字，如〔2026〕
- 序号不加虚位，即1号不是01号
- 示例：XX局〔2026〕15号

## 二、常见公文模板

### 模板1：会议通知
```
关于召开XXXX工作会议的通知

各部门、各科室：

    为深入贯彻落实XXXX工作要求，研究部署下一阶段重点任务，经单位领导研究决定，召开XXXX工作会议。现将有关事项通知如下：

    一、会议时间
    202X年X月X日（星期X）上午9:00，会期半天。

    二、会议地点
    单位X楼X号会议室。

    三、参会人员
    1. 单位领导班子成员；
    2. 各部门主要负责人；
    3. XXXX工作相关业务骨干（名单详见附件）。

    四、会议内容
    1. 传达学习上级关于XXXX的文件精神；
    2. 各部门汇报近期XXXX工作进展情况；
    3. 部署下一阶段重点工作任务；
    4. 领导讲话。

    五、有关要求
    1. 请各部门将参会人员名单于X月X日下午5:00前报办公室；
    2. 请与会人员提前10分钟到场签到，准时参会，不得无故缺席；
    3. 确有特殊原因不能参会的，须提前向办公室履行请假手续；
    4. 会议期间请将手机调至静音，保持会场秩序。

    联系人：XXX    联系电话：XXXX-XXXXXXX

    特此通知。

                                            XX单位办公室
                                          202X年X月X日

附件：参会人员名单
```

### 模板3：工作报告/总结
```
202X年上半年XXXX工作总结

（或：关于XXXX工作情况的报告）

单位领导：

    202X年以来，在单位党组的正确领导下，XX部门紧紧围绕年度重点工作目标，扎实推进XXXX工作，取得了阶段性成效。现将有关情况报告如下：

    一、基本情况与主要做法
    （总体情况概述，用数据说话）
    上半年共完成XXX项任务，同比增长XX%；受理XXX件，办结XXX件，办结率XX%；群众满意度XX%。
    主要做法：
    1. 加强领导，落实责任。...
    2. 健全制度，规范流程。...
    3. 强化培训，提升能力。...
    4. 创新方法，提高效率。...

    二、存在的问题与不足
    （实事求是说问题，不要怕写）
    1. 个别部门重视程度不够，工作推进不均衡。...
    2. 部分业务流程还不够优化，办理时效有待提升。...
    3. 人员业务能力参差不齐，培训力度有待加强。...

    三、下半年工作计划
    （针对问题写改进措施，要具体可落地）
    1. 进一步压实责任，确保年度目标全面完成。...
    2. 优化业务流程，简化审批环节，提升办事效率。...
    3. 加强业务培训，计划组织X期专题培训，覆盖全员。...
    4. 完善考核机制，将XXXX工作纳入部门年度绩效考核。...

    以上报告，请审阅。


                                            XX部门
                                          202X年X月X日
```

## 三、制度文件参考模板

### 模板5：制度/办法/规定
```
XX单位XXXX管理办法（试行）

第一章  总则
第一条  目的依据。为规范XXXX管理工作，根据《XX法》、《XX条例》以及上级《XX规定》（XX〔202X〕XX号），结合本单位实际，制定本办法。
第二条  适用范围。本办法适用于本单位各部门、各科室以及全体工作人员。
第三条  基本原则。XX工作应当遵循依法依规、公开公平、权责一致、高效便民的原则。
第四条  职责分工。XX科负责XX工作的统筹协调；各部门负责本部门XX事项的具体落实；财务科负责经费保障；办公室负责监督检查。

第二章  XXXX的内容与标准
第五条  XXXX分为A类、B类、C类三类。
    （一）A类：指XXXX的情形，具体包括：...
    （二）B类：指XXXX的情形，具体包括：...
    （三）C类：指XXXX的情形，具体包括：...
第六条  XXXX的标准为：
    （一）A类标准：...
    （二）B类标准：...
    （三）C类标准：...

第三章  办理程序
第七条  申请。申请人填写《XX申请表》，附相关证明材料，向所在部门提出申请。
第八条  审核。部门主管在3个工作日内完成初审，签署意见后报XX科。
第九条  复核。XX科在5个工作日内完成复核，必要时可组织调查核实。
第十条  审批。根据审批权限分级表，报相应领导审批。
第十一条  执行。审批通过后，由XX科负责执行，并将结果反馈申请人。

第四章  监督与责任
第十二条  建立XX工作公示制度，除涉密事项外，办理结果在单位内部公示3个工作日，接受群众监督。
第十三条  XX科定期对本办法执行情况进行检查，每年至少1次专项检查。
第十四条  有下列情形之一的，追究相关责任人责任：
    （一）弄虚作假、隐瞒真实情况的；
    （二）滥用职权、违规审批的；
    （三）玩忽职守、造成损失的；
    （四）泄露涉密信息的。
    情节较轻的：批评教育、绩效考核扣分；
    情节较重的：通报批评、党纪政务处分；
    构成犯罪的：移交司法机关处理。

第五章  附则
第十五条  本办法由XX科负责解释。
第十六条  本办法未尽事宜，参照国家及上级有关规定执行。
第十七条  本办法自印发之日起施行。原《XX单位XXXX管理办法》（XX〔2020〕X号）同时废止。
```

## 四、保密提醒（文件使用注意事项）

1. **不要直接套用以上模板的内容**，请根据本单位实际情况修改后使用
2. 文件落款日期用中文大写还是阿拉伯数字，按你们单位以往的习惯保持一致即可
3. 涉密文件请严格标注密级（秘密/机密/绝密），并控制知晓范围
4. 电子版文件命名规范："日期-发文部门-文件名.docx"，例如"20260818-人事科-关于XX同志任职的通知.docx"
