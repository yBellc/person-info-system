# 系统操作手册 - 各模块详细指南

## 一、工作台（Dashboard）使用说明

### 1.1 页面组成
从上到下依次为：
1. 顶部欢迎条：显示问候语、角色标签、当前日期
2. 通知公告栏：显示最新通知公告，可点击查看详情
3. 待办中心卡片（3个）：待我审批 / 我发起的 / 未读消息，点击对应按钮进入
4. 快捷入口（8个）：流程审批、智能表格、人员档案、在职管理、离职/批量、统计报表、通知公告、待办事项
5. 个人待办事项：自建的个人待办，支持新建、完成、删除、分页
6. 【领导/管理员可见】数据大屏、4个总览数字、人员结构图表、预警提醒、最近操作日志

### 1.2 快捷入口说明
| 入口名称 | 功能说明 | 适用角色 |
|---------|---------|---------|
| 流程审批 | 发起新审批、处理待我审批的流程、查看审批记录 | 全员 |
| 智能表格 | AI创建表格、填写任务、收集结果导出、查看统计 | 全员 |
| 人员档案 | 新增/修改/查询人员档案、上传照片、导出Excel | 人事/领导/管理员 |
| 在职管理 | 考勤管理、奖惩登记、绩效记录、调岗调薪 | 人事/领导 |
| 离职/批量 | 离职申请审批、批量入职导入、批量调岗 | 人事/管理员 |
| 统计报表 | 人员统计、花名册报表、AI生成报表、模板导出 | 领导/管理员 |
| 通知公告 | 发布通知、查看已读状态、全部标记已读 | 全员(发布需管理员) |
| 待办事项 | 新增个人待办、标记完成、删除、分页查看 | 全员 |

## 二、人员档案管理模块

### 2.1 新增人员档案
1. 点击左侧菜单「人员档案」→ 右上角「+ 新增人员」
2. 必填项：姓名、身份证号、部门、岗位、入职日期
3. 可选项：照片上传、政治面貌、学历、联系方式、紧急联系人、自定义字段
4. 点击「保存」完成录入

### 2.2 查询人员
1. 顶部搜索框支持按姓名/部门/工号模糊搜索
2. 筛选条件支持：部门、岗位、职务、政治面貌、学历、人员状态
3. 点击记录可查看档案详情，支持编辑、导出

### 2.3 导入人员（批量入职）
1. 点击「批量导入」→ 下载模板
2. 按模板格式填写Excel，身份证号、入职日期等列格式需正确
3. 上传Excel文件，系统自动解析并预览
4. 确认无误后点击「导入」，支持错误提示

### 2.4 导出数据
1. 支持导出当前筛选结果为Excel
2. 导出时秘密级字段会自动脱敏（身份证号、手机号等部分打码）
3. 低密级用户无法导出高密级人员的完整数据

## 三、流程审批模块

### 3.1 发起新流程
1. 进入「流程审批」→ 点击「+ 发起审批」
2. 选择流程模板（请假/报销/用印/出差/调岗等）
3. 按表单填写内容，*号为必填项
4. 可上传附件（支持PDF/Word/Excel/图片，单文件≤10MB）
5. 点击「提交」，流程进入待审批状态

### 3.2 处理待我审批
1. 「待我审批」标签页显示所有需要你审批的流程
2. 点击记录查看详情 → 填写审批意见（必填，尤其是拒绝时）
3. 点击「同意」通过或「拒绝」驳回（驳回需写明理由）
4. 审批完成后流程流转到下一节点或结束

### 3.3 查看审批记录
1. 「我发起的」标签页：查看你发起的所有流程及其状态
2. 「我已审批」标签页：查看你曾经审批过的流程
3. 「审批记录」标签页（领导/管理员可见）：查看全单位已完成的审批流程
4. 审批完成后：报销类流程可下载「凭证」，其他流程可下载审批单PDF

### 3.4 撤销与催办
1. 我发起的流程在未审批前可点击「撤销」
2. 流程长时间未处理可点击「催办」，系统会给审批人发消息提醒

---

## 四、智能表格模块

### 4.1 创建表格
1. 方式一：手动创建字段（文本/数字/日期/选择/人员选择）
2. 方式二：AI自动生成：在输入框描述需求（例如"员工家庭情况统计表，包含姓名、家庭住址、家庭成员信息、联系电话"），AI会推荐字段，确认后自动生成

### 4.2 下发填写任务
1. 创建好表格后，点击「下发」
2. 选择填写对象：按部门 / 按岗位 / 按指定人员
3. 设置截止日期、填写说明
4. 点击确认后，系统会给每位填写人发消息通知

### 4.3 填写表格
1. 在「待我填写」标签页找到任务，点击「去填写」
2. 按字段填写，支持保存草稿、最终提交
3. 若被退回：按退回理由修改后重新提交

### 4.4 收集结果
1. 下发人在「收集结果」中查看填写进度、已提交/未提交人数
2. 支持导出所有填写结果为Excel
3. 支持"下载原模板"：每人的填写内容单独生成一份Word文档，打包为ZIP下载

---

## 五、在职管理模块

### 5.1 考勤管理
1. 支持按部门/月份查询考勤记录
2. 支持从Excel批量导入考勤数据（模板下载→填写→上传）
3. 异常考勤（迟到/早退/旷工）支持手动标记并写原因

### 5.2 奖惩管理
1. 新增奖惩记录：类型（奖励/惩罚）、事由、金额、依据文件
2. 记录永久保存，作为绩效考核参考

### 5.3 调岗调薪
1. 发起调岗/调薪申请
2. 人事科审核 → 部门主管 → 分管领导
3. 审批通过后，人员档案自动更新新岗位/新薪资

---

## 六、离职/批量模块

### 6.1 离职申请
1. 员工本人或人事科发起离职申请
2. 填写离职类型（主动/被动/到期）、离职原因、预计离职日期
3. 按节点审批：部门主管 → 人事科 → 分管领导
4. 审批通过后，进入交接环节

### 6.2 离职交接
1. 工作交接清单：由交接人填写，交接内容逐项勾选
2. 物品交接：电脑、工牌、钥匙、U盘等办公物品归还
3. 财务交接：结清借款、报销
4. 每一步交接完成后，相关方签字确认
5. 全部交接完成后，账号自动停用，状态改为"已离职"

### 6.3 批量操作
1. 批量调岗：选择人员 → 选择新部门/岗位 → 一键调整
2. 批量入职：参考 2.3 批量导入

---

## 七、消息中心

### 7.1 消息类型
- 审批通知：你有待审批的流程 / 你发起的流程有更新
- 表格通知：你有新的填写任务 / 你下发的表格有人提交
- 系统通知：账号异常、密码即将过期等
- 通知公告：管理员发布的正式通知

### 7.2 操作
- 点击消息可直接跳转至对应页面处理
- 支持全部标记为已读
- 未读消息数在工作台顶部右上角显示为红点

---

## 八、账号安全与个人设置

### 8.1 修改密码
1. 右上角头像 → 个人中心 → 修改密码
2. 密码要求：≥8位，同时包含字母、数字、符号中的至少3种
3. 密码每90天过期一次，系统会提前提醒强制修改

### 8.2 账号锁定
1. 连续5次密码错误，账号自动锁定30分钟
2. 紧急情况联系单位管理员手动解锁

### 8.3 登录注意
- 新登录会踢掉之前的登录（防止多设备同时在线）
- 30分钟无操作自动登出（会提前1分钟提醒）
- 公共电脑用完务必点击「退出登录」
