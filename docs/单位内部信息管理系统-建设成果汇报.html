第一章　项目背景与建设目标
1.1 建设背景

当前单位正处于数字化转型关键阶段，原有办公流程以手工、纸质为主，存在以下突出问题：

  • 人员档案管理混乱：员工信息分散在Excel、Word、纸质档案中，查询、更新、统计极其不便
  • 流程审批效率低：请假、报销、用章、出差等申请以纸质单据流转，签字耗时、易遗失、追溯困难
  • 新员工建档工作量大：人事逐个录入简历信息，费时费力且易出错
  • 数据统计无法支撑决策：无法实时了解人员结构、部门分布、休假情况等关键数据
  • 账号与权限管理不规范：缺乏统一账号体系、权限控制和登录审计

基于以上痛点，立项建设"单位内部信息管理系统"，实现人员档案数字化、流程审批电子化、人事管理智能化、数据统计可视化的四大目标。

2.2 部署方式

系统采用单进程一体化部署方案，前后端不拆分，运维简单，特别适用于单位内网环境：

  • 本地访问：浏览器打开 http://127.0.0.1:8000
  • 内网部署：内网服务器运行，员工通过 http://服务器IP:8000 访问
  • 无需分别启动前端后端：单一 Python 进程即可完整运行
  • 零外网依赖：全部功能离线可用，适配单位仅内网的特点

3.2 智能简历识别模块（新增核心功能）

🤖 AI关键字引擎 + 正则识别，无需额外付费对接大模型

1
多格式兼容：同时支持 Word（.docx）、Excel（.xlsx）两种简历格式
2
双引擎识别：表格布局解析 + 段落文本正则，覆盖90%以上简历模板
3
字段自动提取：姓名、身份证、学历、电话等30+字段自动抽取
4
子表识别：家庭成员、教育经历、工作经历等列表自动拆分入库
5
员工自助：个人中心上传简历 → 预览识别 → 一键填充个人信息
6
人事批量：上传简历压缩包 → 智能识别 → 批量创建人员档案+账号
应用场景1：员工自助完善个人信息
  1. 员工登录系统 → 进入"我的信息" → 点击"上传简历自动填充"
  2. 上传本人简历文档（.docx / .xlsx） → 点击"智能识别"
  3. 系统弹出识别结果预览：显示识别到的30+字段、家庭成员/教育经历数量
  4. 员工可选择："仅填充空字段"（保留已填信息） 或 "覆盖已有值并保存"
应用场景2：人事批量导入简历建档
  1. 人事管理员 → 进入"人事账号管理 → 简历导入"标签页
  2. 选择目标单位、统一部门/岗位、初始密码模式（身份证后6位/统一密码）
  3. 批量拖拽上传员工简历文件（支持多文件同时上传）
  4. 点击"预览识别结果" → 逐个查看识别出的字段，确认无误
  5. 点击"一键创建账号" → 系统自动完成建档+创建账号+自动生成用户名
  6. 成功/失败列表即时展示，失败可查看原因（如身份证冲突）

审批核心特性
  • 动态匹配审批人：根据申请人所在部门，自动找到对应的部门负责人、人事、财务、单位管理员进行审批，无需为每个流程手动指定审批人

3.5 人事批量注册与账号管理
整体流程（人事操作）
Step 1

导入员工名单

人事在"名单管理"中手动添加或批量导入员工姓名+身份证号，建立待注册名单池

Step 2

批量创建账号 / 智能简历导入

方式A：勾选待注册名单 → 批量创建账号（初始密码身份证后6位）
方式B：上传简历文件 → 智能识别 → 批量创建档案+账号（新增）

Step 3

通知员工登录

告知员工用户名与初始密码，员工首次登录后强制修改密码，自行完善信息

Step 4

账号全生命周期管理

管理员可查看账号列表、重置密码、启用/停用账号，离职人员一键停用

账号管理核心能力
  • 用户名自动生成：优先手机号，其次姓名拼音+序号
  • 首次登录强制改密：初始密码使用一次后必须修改，保障安全
  • 身份证校验：18位身份证格式校验+校验码验证，重号自动拦截
  • 单位层级管控：超管管全单位，单位管理员仅管本单位及下属单位
  • 申请管理员通道：普通员工可在线申请成为单位管理员，超管后台审批

第四章　系统亮点与创新
4.1 智能简历识别：自动提取+批量建档
🚀 效率提升对比：传统人事逐个录入需10-15分钟/人 → 智能识别仅需5-10秒/人，整体效率提升100倍。批量导入100人从1天缩短至10分钟完成。
  • 无需AI大模型，纯本地引擎：基于关键字匹配+位置启发+正则提取的混合识别引擎，纯离线运行，不依赖任何第三方API，完全符合内网安全要求
  • 双重覆盖：表格+段落：传统方案只能解析表格简历，本系统同时支持段落格式简历，实际兼容率从60%提升至90%以上
  • 字段智能标准化："政治面貌"自动将"党员"标准化为"中共党员"，"性别"中英文自动归一，"出生年月"6种日期格式自动统一为YYYY-MM-DD
  • 误识别防护：内置否定前缀机制，避免把"家庭成员姓名""配偶职务"误提取为员工本人的姓名和职务
  • 双向应用：既支持员工个人上传简历自助填档案，也支持人事批量导入简历一键创建账号+档案
4.2 动态审批路由：自动匹配审批人

传统流程系统需要管理员为每个流程手动配置审批人，人员变动后配置即失效。本系统实现规则化自动匹配：

节点类型匹配规则说明
部门负责人dept_manager根据申请人所在部门，自动查找部门负责人审批
人事审核role:hr自动匹配单位内拥有人事角色的账号
财务审核role:finance自动匹配单位内拥有财务角色的账号
单位管理员unit_admin自动匹配单位管理员进行终审
指定人员fixed:{user_id}固定审批人（适用于特殊场景）

优势：部门负责人、人事、财务等人员变动后，审批链自动生效，无需修改任何流程配置。

4.3 多级权限体系：分级管理
角色权限范围典型使用场景
超级管理员全系统所有功能，可管理全部单位系统最高权限，仅2-3人持有

4.4 安全加固：账号安全与审计
  • 完整日志审计：登录日志（成功/失败+IP+浏览器）、操作日志（改密/建档/启停账号等），审计数据不可篡改
  • 软删除机制：人员档案、账号、流程均为软删除（标记is_deleted），误删可恢复
  • 敏感字段脱敏：身份证号除详情页外一律脱敏显示
  • 首次登录强制改密：人事批量创建的账号，员工首次登录必须修改密码，避免初始密码泄露风险
