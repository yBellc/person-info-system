## 8. 涉密分级管控详解

### 8.1 核心概念

```
数据密级（字段级）          用户 ClearanceLevel（0~3）
    │                           │
    ▼                           ▼
公开(0) 内部(1) 秘密(2) 机密(3)    0=公开 1=内部 2=秘密 3=机密
    │                           │
    └─────── 比较 ──────────────┘
              │
         用户等级 >= 数据密级？
              │
         ├─ 是 → 正常显示
         └─ 否 → 显示 "****"
```

### 8.2 关键代码位置

| 文件 | 功能 |
|------|------|
| `backend/app/core/permissions.py` | 密级判断、权限过滤 |
| `backend/app/routers/persons.py` | 人员列表/详情接口（含脱敏） |
| `backend/app/services/ai_service.py` | AI 问答涉密过滤 |

### 8.3 核心函数

```python
# backend/app/core/permissions.py

def can_view_person(user, person):
    """用户能否查看某人员档案"""
    # 超管可看全部
    if user.role == "super_admin":
        return True
    # 用户可查看自己的档案（不脱敏）
    if user.person_id == person.id:
        return True
    # 同单位可查看
    if user.unit_id == person.unit_id:
        return True
    return False

def filter_persons_by_clearance(user, persons):
    """根据密级过滤人员列表"""
    result = []
    for p in persons:
        # 用户始终可查看自己
        if user.person_id == p.id:
            result.append(p)
            continue
        # 密级过滤
        if user.clearance_level < p.clearance_level:
            continue  # 密级不足，跳过
        result.append(p)
    return result
```

### 8.4 导出脱敏

```python
# 导出 Excel/Word 时自动脱敏
def mask_sensitive(value, level, user_level):
    """根据用户密级脱敏"""
    if user_level >= level:
        return value
    return "****"
```

## 11. 常见问题 FAQ

### Q1: 重启电脑后打不开系统？

**原因**：8000 端口后端未启动，或 5173 开发服务器已关闭。

**解决**：
1. 双击 `START.bat` 启动服务
2. 或安装自启服务：`INSTALL_SERVICE.bat`（需管理员权限）
3. 访问地址：`http://127.0.0.1:8000`（**不是** 5173）

### Q2: AI 问答回答"该问题在知识库中暂未收录"？

**原因**：知识库中没有相关文档，或检索未命中。

**解决**：
1. 知识库管理页 → 上传相关文档
2. 点击"重建知识库"入库
3. 检查"服务状态"页 Embedding 模型是否为 BGE

### Q3: 登录后看不到人员信息？

**原因**：用户 `person_id` 未关联，或密级不足。

**解决**：
1. 用超管登录（admin/Test@1234）
2. 在"人员管理"中手动关联用户和人员档案
3. 检查用户 `clearance_level` 是否 >= 数据 `sensitive_level`

### Q4: 前端页面空白/报错？

**原因**：浏览器缓存旧资源，或构建产物未更新。

**解决**：
1. `Ctrl + F5` 强制刷新
2. 或重新构建：`cd frontend && npm run build`

### Q5: AI 模型加载失败？

**原因**：模型文件缺失或路径错误。

**解决**：
1. 确认 `backend/storage/models/Qwen2-0.5B-Instruct/` 存在
2. 确认 `backend/storage/models/bge-small-zh-v1.5/` 存在
3. 检查环境变量 `BGE_MODEL_PATH` 是否正确

### Q6: 涉密字段显示 "****" 不正常？

**原因**：这是正常行为，用户密级低于数据密级。

**解决**：用更高密级账号登录（如 admin，等级3）。
