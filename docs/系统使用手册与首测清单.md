# 单位内部信息管理系统 — 使用手册与首测清单

---

## 一、系统架构总览

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Vue 3 + Element Plus + Vite | 单页应用，响应式布局 |
| 后端 | Python FastAPI + SQLAlchemy | RESTful API，自动生成 Swagger 文档 |
| 数据库 | SQLite（开发）/ PostgreSQL（生产） | 轻量级，无需额外安装 |
| 认证 | JWT Token | 无状态认证，7天有效期 |

### 目录结构

```
person-info-system/
├── backend/                    # 后端
│   └── app/
│       ├── main.py             # 应用入口（路由注册、初始化）

│       │   └── workspace.py    # 通知、待办
│       ├── routers/            # API路由
│       │   ├── auth.py         # 登录/注册/人事批量注册
│       │   ├── persons.py      # 人员档案管理
│       │   ├── units.py        # 单位管理
```

| 模块 | 路由前缀 | 功能 |

## 四、系统启动步骤

### 首次使用

1. **双击** `一键启动.bat`
   - 自动安装后端依赖（首次约2分钟）
   - 自动安装前端依赖（首次约3分钟）
   - 启动后端服务（端口 8000）
   - 启动前端服务（端口 5173）
   - 自动打开浏览器

2. **双击** `【双击创建测试账号】.bat`
   - 创建 4 个测试单位
   - 创建 8 个测试账号（密码统一 test123）
   - 创建 4 个流程模板（请假/报销/用章/出差）

### 日常使用

直接双击 `一键启动.bat` 即可，浏览器打开 http://127.0.0.1:5173

### 停止服务

关闭弹出的两个命令行窗口即可。

## 八、常见问题

| 问题 | 解决方案 |
|------|----------|
| 浏览器打不开 | 检查两个命令行窗口是否正常运行，看报错信息 |
| 登录提示 401 | 确认账号密码正确，测试账号密码统一为 test123 |
| 页面白屏 | 按 F12 打开控制台查看错误，刷新页面 |
| 流程审批找不到人 | 确认审批人账号已创建且角色正确 |
| 菜单不显示 | 不同角色看到的菜单不同，用 leader 登录可看到全部菜单 |
| 修改密码后进不去 | 清除浏览器缓存（Ctrl+Shift+Delete），重新登录 |
