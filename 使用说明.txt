============================================
  单位内部信息管理系统 - 使用说明
============================================

一、启动方式
──────────────────────────────────────────────
双击项目根目录下的「启动服务.bat」文件即可。

服务启动后：
  - 前端页面和后端API由同一个Python进程托管
  - 无需单独启动Node.js前端服务
  - 启动后浏览器自动打开 http://127.0.0.1:8000

三、功能菜单说明
──────────────────────────────────────────────
登录后左侧菜单自动展示（根据角色过滤）：

  【工作台】       首页仪表盘，显示待办、通知等统计
  【我的信息】     个人档案维护
  【人员管理】     人员列表管理（管理员）
  【账号管理】     人事批量注册账号（管理员）
  【单位管理】     单位信息管理（超管）
  【组织架构】     部门/岗位/职级管理（管理员）
  【角色权限】     角色/数据权限/字段权限（超管）
  【通知公告】     发布/查看通知公告
  【待办事项】     个人待办管理
  【流程审批】     发起/审批OA流程
  【统计报表】     人员数据可视化与导出

──────────────────────────────────────────────
四、请假审批测试流程
──────────────────────────────────────────────
1. 用普通员工账号（如 office_01 / test123）登录

2. 点击左侧菜单「流程审批」

3. 点击右上角「发起流程」按钮

4. 选择流程模板（如"请假申请"）

5. 填写表单并提交

6. 用审批人账号（如 bgs_leader）在另一个浏览器登录
   → 进入「流程审批」→「待我审批」→ 审批

7. 审批完成后，申请人可在「我发起的」查看状态

──────────────────────────────────────────────
五、部署到单位内网服务器
──────────────────────────────────────────────
1. 将整个项目文件夹复制到服务器
2. 安装 Python 3.9+ 和依赖：
   cd backend && pip install -r requirements.txt
3. 双击「启动服务.bat」或运行：
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
4. 内网其他电脑通过 http://服务器IP:8000 访问

──────────────────────────────────────────────
六、停止服务
──────────────────────────────────────────────
关闭命令行窗口或按 Ctrl+C 即可停止服务。
